## ChinaFlux54站点

> 仅处理日尺度的数据

- `Ta`    : degC
- `RH`    : %
- `VPD`   : kPa
- `Rg`    : 太阳总辐射`Rs`，MJ m-2 d-1
- `Rn`    : MJ m-2 d-1
- `PPFD`  : 光合有效辐射，mol m-2
- `WS`    : m s-1
- `Pa`    : hPa
- `Tsoil` : degC
- `SWC`   : m3 m-3
- `Gs`    : 土壤热通量，MJ m-2 d-1
- `Rain`  : mm/d
- `NEE`   : gCO2 m-2 d-1
- `LE`    : MJ m-2 d-1
- `Hs`    : MJ m-2 d-1
- `Re`    : gCO2 m-2 d-1
- `GPP`   : gCO2 m-2 d-1
