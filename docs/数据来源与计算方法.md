## 1. 强迫场（01_prepare_forcing.R + 06_fill_gaps.R）

### 1.1 两套源数据

**sp31（站点实测，主来源）**

| 列 | 含义 | 单位 |
|---|---|---|
| site | 站点名 | — |
| time | 北京时间（钟面时刻，存成带 Z 的 ISO 格式） | 逐时 |
| Ta | 气温 | °C |
| RH | 相对湿度 | % |
| WS | 风速 | m/s |
| Rs | 向下短波辐射 | W/m² |
| Prcp | 降水 | mm/h |
| Rln_in | 向下长波（**未使用**） | — |

**CMFD（再分析，补缺用）**

| 列 | 含义 | 单位 |
|---|---|---|
| datetime | 世界时 UTC（ISO 带 Z） | 逐时 |
| site | 站点名 | — |
| Temp | 气温 | °C |
| RHum | 相对湿度 | % |
| Wind | 风速 | m/s |
| SRad | 向下短波 | W/m² |
| LRad | 向下长波 | W/m² |
| Prec | 降水 | mm/h |
| Pres | 地面气压 | Pa |

### 1.2 时间对齐

- sp31 的 time 是**北京钟面时间**（虽带 `Z` 后缀，实为 UTC+8 的钟面值，不换算）。
- CMFD 的 datetime 是**真 UTC**，统一 **+8 小时**转成北京钟面时间后再与 sp31 对齐。
- 后续所有时间均按**北京钟面时间**处理（`DEF_simulation_time%greenwich = .false.`，即本地时间）。

### 1.3 补缺

- **补缺测值**（01）：sp31 里为 NA 的 Ta/RH/WS/Rs/Prcp，用 CMFD 同站同时刻的 Temp/RHum/Wind/SRad/Prec 补上（气压、长波 sp31 本来就没有，直接取 CMFD）。
- **补时间缺口**（06）：对每站按「模拟年份完整逐时轴」找缺失的时刻（开头/结尾/中间），从 CMFD 取对应时刻补上，保证 Met.nc 覆盖完整自然年。原 CMFD 覆盖 2000–2024。

### 1.4 单位换算（→ CoLM 8 变量）

| CoLM 变量 | 公式 | 单位 |
|---|---|---|
| Tair | `Ta + 273.15` | K |
| Psurf | `Pres`（原样） | Pa |
| Precip | `Prcp / 3600` | mm/h → kg/m²/s |
| Wind | `WS`（原样） | m/s |
| SWdown | `Rs`（原样） | W/m² |
| LWdown | `LRad`（原样） | W/m² |
| Qair | 见下 | kg/kg |

**比湿 Qair**（由 RH 和气压反算）：

```
es = 6.112 · exp(17.62·Ta / (243.12 + Ta))     # 饱和水汽压 (hPa)
e  = RH / 100 · es                             # 实际水汽压 (hPa)
Qair = 0.622 · e / (Psurf/100 - 0.378·e)       # 比湿 (kg/kg)
Qair 截断到 [0, 0.05]
```

输出：`results/forcing_self.csv`（site, time, Tair, Qair, Psurf, Precip, Wind, SWdown, LWdown）。

## 2. LAI（02_prepare_lai.R）

- **来源**：GLASS V6.1 LAI（`LAI_MODIS_GLASS_G005D_<年份>_v20260608.nc`），全球 0.05°（7200×3600），时间维 46 期 = **8 天合成**（每年 46 期，起始 1 月 1 日），单位 m²/m²。
- **提取**：每站取**最近格点**（`which.min(abs(lon-lat))`，注意 lat 从北到南排列）。
- **聚合**：46 期 8 天 → 按每期**起始日期所在月份**平均，得 12 个月均值（m1~m12）。
- 站点年份取自 `ChinaFlux_37sites_igbp_mapping.csv` 的 `years` 列（燕山 ENF 无年份，补 2020–2021）。
- 输出：`results/lai_monthly.csv`。

## 3. 土壤（03_prepare_soil.R）

### 3.1 来源

SoilGrids（ISRIC 全球土壤库）soil5 数据集（Dai et al. 2019），30" 网格，按 **CoLM/CLM 8 层剖面**提取：

| 层 | 深度 (m) |
|---|---|
| 1 | 0 – 0.0451 |
| 2 | 0.0451 – 0.0906 |
| 3 | 0.0906 – 0.1655 |
| 4 | 0.1655 – 0.2891 |
| 5 | 0.2891 – 0.4929 |
| 6 | 0.4929 – 0.8289 |
| 7 | 0.8289 – 1.3828 |
| 8 | 1.3828 – 3.8019 |

### 3.2 17 原始参数（soil5 直接给）

`vf_gravels, vf_quartz, vf_om, vf_sand, vf_silt, vf_clay, theta_s, log_k_s, psi_s, lambda, csol, VGM_theta_r, VGM_alpha, log_VGM_n, tksatu, tkdry, tksatf`

（`vf_*` 为体积分数、`theta_*` 为含水量、`log_k_s/log_VGM_n` 为**以 10 为底的对数**，其余含义见 CoLM 源码。）

**提取方法**（脚本 `data-raw/soil/ChinaFlux_soil5_extraction/extract_soil5_batch_correct.py`）：
- 数据源：soil5 二进制栅格，30"（=1/120°），全球 43200 列 × 21600 行，每像元 8 字节 double（小端）；每参数一个 `tar.gz` 归档，内含 8 层文件（文件名 `_l1`~`_l8`）。
- 站点定位：`row = (90 − lat)×120 + 1`，`col = (lon + 180)×120 + 1`（从 90°N、180°W 起算）。
- 读取：`tar -xzOf` 流式读（不完整解压），目标像元偏移 `offset = (row−1)×43200×8 + (col−1)×8`，读 8 字节 double。
- 注意：`psi_s` 归档里层顺序是乱的（6,1,8,7,2,5,4,3），按文件名 `_l%d` 解析层号，不按归档顺序。
- 去重：相同 (row,col) 的站点只读一次像元，值共享。
- 校验：`verify_batch_vs_perstation.py`（批量 vs 单站一致）、`regression_cnqia_check.py`（与千烟洲回归核对）、`quick_completeness_check.py`（完整性）。
- 输出：`data-raw/soil/ChinaFlux_soil5_final/ChinaFlux_soil5_17params_raw.csv`（site, lon, lat, row, col, parameter, layer1..8）。

### 3.3 7 派生参数（CoLM 官方公式，见 `data-raw/soil/ChinaFlux_soil5_final/ChinaFlux_soil5_derived_parameters_method.md`）

颗粒密度：砾石 2.80、有机质 1.30、矿物 2.71 g/cm³。

```
BD_ave [g/cm³]   = vf_gravels·2.80 + vf_om·1.30 + (vf_sand+vf_silt+vf_clay)·2.71
soil_BD_all      = BD_ave × 1000                    # kg/m³
soil_wf_i        = vf_i · ρ_i / BD_ave              # 质量分数（无量纲）
soil_OM_density  = vf_om · 1.30 × 1000              # kg/m³
soil_k_solids    = 2.875^vf_gravels · 0.25^vf_om · k_minerals^a   # W/m/K，Balland-Arp
                  其中 k_minerals = 7.7^vf_quartz · k_minerals_o^(1-vf_quartz)
                  a = vf_sand + vf_silt + vf_clay
```

### 3.4 换算到 site.nc 的 26 个土壤变量（× 10 层）

| site.nc 变量 | 来源 |
|---|---|
| soil_k_s | `10^log_k_s`（cm/day，log10 → 线性） |
| soil_n_vgm | `10^log_VGM_n`（log10 → 线性） |
| soil_vf_gravels/om/sand/clay/quartz_mineral、theta_s/theta_r、psi_s、lambda、csol、tksatu/tksatf/tkdry、alpha_vgm | 17 原始参数原样 |
| soil_wf_gravels/sand/clay/om、BD_all、OM_density、k_solids | 7 派生参数 |
| soil_L_vgm | 常数 0.5（VGM 曲折度） |
| soil_BA_alpha / soil_BA_beta | 参考 CN-Cng 占位值（CoLM 热导率 Balland-Arp 参数，影响小） |

**8 层 → 10 层**：site.nc 的 soil 维是 10 层，第 9、10 层 = 第 8 层（最深层重复；CoLM 内部再按 8 层剖面读取）。

输出：`results/soil_params.csv`（site, layer 1–10, 26 个土壤变量）。

## 5. 生成 site.nc / Met.nc / namelist（05_build_site_data.R）

- **Met.nc**：逐时 3600 s，时间原点 = 模拟起始年 1 月 1 日；末尾**追加 1 个哨兵步**（最后一步 +3600 s，数值复制），对应 `forcing.nml` 的 `endyr = 末年 + 1`，防止模拟在末尾读强迫时挂起。
- **site.nc**：49 变量完整版（结构照抄已验证的 CN-Cng 模板）：
  - 14 个站点专属变量（经纬度、参考/冠层高、IGBP/USGS、PFT、year_qc、LAI/SAI）；
  - 26 个土壤变量（10 层，见 §3）；
  - 地形（elevation/sloperatio/lakedepth=1.0/elvstd=0.0）；
  - 土壤反照率 4 个 + soil_texture。
- **SAI**：常数 `sai0_igbp`（ENF/EBF/DBF=2.0，MF/WSA=0.5，SAV/GRA/WET/CRO=0.2）。
- **LAI_pfts / SAI_pfts**：活跃 PFT（pfttyp≠0）取整层 LAI/SAI，裸土取 0。
- **案例目录名**：ASCII 拼音（中文路径会让 Fortran 打不开文件）。
- 输出：`cases/self_version/<拼音>_<年份>/` 下 `met/*_Met.nc`、`site.nc`、`case.nml`、`forcing.nml`。

## 7. 模型配置（case.nml / forcing.nml）

- kernel：`default`（`SinglePoint LULC_IGBP CaMaOFF CROPOFF`，**无 BGC、无作物模块**）
- 时间：`greenwich=.false.`（本地时间），内部步长 1800 s，history 逐时输出
- `spinup_repeat=0`（不做预热，首年含土壤水瞬变）
- `DEF_HIST_FREQ='HOURLY'`，`DEF_WRST_FREQ='MONTHLY'`
- forcing.nml：8 槽 `Tair/Qair/Psurf/Precip/NULL/Wind/SWdown/LWdown`，插值 `linear/…/nearest/…`

## 8. 通量提取（08_extract_flux.R）

从逐时 history 提取 6 个变量，聚合到日尺度：

| 输出变量 | history 变量 | 计算 | 单位 |
|---|---|---|---|
| ET | f_fevpa | `sum(f_fevpa × 3600)`（日累加） | mm/d |
| H | f_fsena | 日平均 | W/m² |
| Rnet | f_rnet | 日平均 | W/m² |
| Qg | f_fgrnd | 日平均 | W/m² |
| GPP | f_assim | `mean(f_assim) × 1e6` | µmol/m²/s |
| Resp | f_respc | `mean(f_respc) × 1e6` | µmol/m²/s |

（f_fevpa 是 mm/s，×3600=mm/h，日累加=mm/d；f_assim/f_respc 是 mol/m²/s，×1e6=µmol/m²/s。）

输出：`results/sim_daily.csv`。

## 9. 验证口径（09_validate.R）

观测换算到与模拟一致的单位后，按站点+日期匹配，逐站逐变量算指标。

| 变量 | 观测换算 | 模拟 |
|---|---|---|
| ET | ET 列（mm/d，无则 `LE×86400/2.45e6`） | mm/d |
| H | `Hs`（已是 W/m²，不换算） | W/m² |
| Rnet | `Rn`（已是 W/m²，不换算） | W/m² |
| GPP | `GPP ÷ 12 × 1e6 ÷ 86400`（gC→µmol/m²/s，**÷12 是碳摩尔质量**） | µmol/m²/s |
| Resp | `RE ÷ 12 × 1e6 ÷ 86400` | µmol/m²/s |
| Qg | 观测无，跳过 | — |

指标（每站每变量，R² 要求配对样本 ≥2，否则 NA）：

```
R² = cor(obs, sim)²
RMSE = sqrt(mean((sim - obs)²))
MAE = mean(|sim - obs|)
Bias = mean(sim - obs)
N = 配对天数
```

## 10. 已知问题与说明

1. **长岭（水稻）太阳辐射异常**：sp31 里长岭 7 月 Rs 仅 40 W/m²（正常约 200），导致其 ET/H/Rnet 精度差，其余变量正常。
2. **缺观测**：GPP/Resp 缺临泽、多伦、锡林浩特刈割；Rnet 缺三江源（无 Rn 列）；燕山两站 Rn 仅 3 个有效天。
3. **首年瞬变**：spinup=0，每站第 1 年有土壤水瞬变（未跳过）。
4. **kernel 无 BGC/CROP**：GPP 为光合碳同化、Resp 为自养呼吸，不含异养呼吸；水稻/农田站无灌溉与作物物候。
5. **H 整体偏低**：感热是能量平衡残差，误差累积所致。
